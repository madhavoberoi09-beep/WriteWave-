# 📝 WriteWave

A modern, elegant blogging platform built with React, Vite, TailwindCSS, and TypeScript — designed for seamless reading, writing, and publishing.

# 🚀 Live Demo

🔗 Live Website:
https://profound-rugelach-29fe0f.netlify.app/

# 📌 Features

✔️ Beautiful, modern UI
✔️ Homepage with featured blog posts
✔️ Smooth navigation and article browsing
✔️ Responsive design for mobile & desktop
✔️ Optimized build with Vite
✔️ Easy to deploy and scale

3🛠️ Tech Stack

React + Vite

TypeScript

TailwindCSS

Node.js

Netlify (for deployment)                                        
# 📂 Project Structure
WriteWave/
│── client/               # Frontend source code
│   ├── src/              # Components, pages, UI pieces
│   ├── assets/           # Images and static assets
│   └── index.html        # Base HTML file
│
│── shared/               # Shared utilities and configs
│── attached_assets/      # Local assets
│── server/               # (Optional) API or backend stubs
│
│── dist/                 # Production build generated by Vite
│── package.json
│── vite.config.ts
│── tsconfig.json
│── README.md
🌐 Deployment (Netlify)

The project is pre-configured for Netlify.
You can deploy by uploading the dist/ folder or connecting your GitHub repo.

Build command:

npm run build


#Publish directory:

dist/public
